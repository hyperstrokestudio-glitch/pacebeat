# PaceBeat

Expo SDK 57 running metronome for Android (Play Store–ready via EAS). One screen: BPM readout, audio-synced beat pip, tactile controls, and background playback.

## Develop

```bash
npm install --legacy-peer-deps
npm start
```

## Checks

```bash
npm run typecheck
npm test
```

Package id: `com.pacebeat.app`
